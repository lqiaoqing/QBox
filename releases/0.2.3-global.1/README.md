# QBox 全局名称共享试用版

双击 [QBox.GlobalTrial.exe](QBox.GlobalTrial.exe)，需要 Windows x64 和 .NET 10 桌面运行时。窗口和托盘均标有“全局共享试用”。标准发布版现为 0.2.4。

- 唤起键为 **Ctrl+Alt+空格**。正式版仍使用原来的双击 Ctrl。
- 配置、历史、索引全部独立存放在 `%LOCALAPPDATA%\QBox.GlobalTrial`。本机已准备好 C、D 盘的全局共享索引及当时的增量记录，可以直接搜索。
- **默认关闭后台自动更新**，试用期间索引不会自动追赶文件变化。需要持续试用时，可从菜单启用自动更新；管理员工作进程只更新试用目录。
- 对比内存前，请从托盘退出标准版，再运行试用版，并使用相近的查询和等待时间。本次构建没有停止正在运行的标准版。
- 结束试用时从托盘退出全局版，再运行标准版即可。原程序、原配置和原索引均保留。

本机副本捕获于 2026-11-15 17:50 左右，共享后基础索引由 425.93 MiB 降至 287.33 MiB，减少 **138.61 MiB**。这是索引文件载荷的减少，不能直接从任务管理器的私有内存数值中减去同样大小。

本版保留原匹配、排序和 USN 覆盖层策略，将基础名称文本改为全局复用。此前相同逻辑数据的对照中，部分英文宽查询比局部共享慢约 20%～39%；此次提供独立版本用于判断实际体验，尚未证明全量建库速度与标准版相同。实现、验证及复现入口见 [试用记录](../../docs/2026-11-15-全局共享试用版.md)。

个人索引不随 EXE 或仓库分发。在其他电脑或其他用户下使用，需要通过菜单建立自己的索引。分发程序时请保留本目录中的许可文件。
