## 后续验收清单

- [ ] **工作台**：左侧依次为搜索、剪贴板、截图与贴图、桌面整理、翻译，设置在底部；右侧提供完整操作、历史或参数。普通打开工作台时恢复上次使用的工具；快捷搜索展开时始终进搜索页。对照主图的留白、字体层级、图标、选中态、底栏和窄窗布局。
- [ ] **搜索**：第一次双 Ctrl 打开快捷搜索；快捷栏在前台时再次双 Ctrl 进入工作台搜索页，保留搜索词和选中目标。验证键盘、中文输入、续填后仍打开正确目标、完整窗口底栏保留耗时。当前搜索速度和排序保持 0.2.7 基线。
- [ ] **剪贴板**：默认 `Ctrl+反引号`（`~` 同键），独立面板优先靠近当前输入位置并允许记住位置。搜索、类型筛选、置顶与最近分组清楚；文字看摘要、图片看缩略图、文件看文件名，不展示 `CF_DIB` 等内部格式。列表紧凑且密度可调整。上下键选中，Enter 或双击贴回原窗口，Shift+Enter 纯文本粘贴，完成或 Esc 后归还焦点；展开到工作台保留筛选和选中项。
- [ ] **截图与贴图**：默认 `Ctrl+1` 直接进入屏幕选区；悬停识别窗口或元素，手动拖框可替代自动选区。确认后工具栏靠近选区，提供标注、复制、保存、贴图、OCR 和翻译。实机行为以 Snipaste / PixPin 的操作方式作参考。
- [ ] **翻译**：默认 `Ctrl+2` 打开独立小面板，原文、译文和复制入口直接可见；长文本可展开到工作台并保留内容。剪贴板文字和截图 OCR 结果可送入翻译，取消后回到原窗口。
- [ ] **桌面整理**：工作台有独立入口，集中管理规则和查看整理前后；真实清理和默认快捷键在该模块立项时确认。
- [ ] **统一快捷键**：可以按键录入、修改、禁用和恢复默认；遇到重复或系统注册失败有明确反馈，失败保留旧键。未实现的工具在设置里标记未启用，不占系统组合键。

验收时每项分别记录 ①视觉与图稿的差距 ②实际操作是否可用 ③对照截图或复现步骤。未实机验证的双 Ctrl、原窗口焦点、输入法、DPI 依旧标未验证；新工具的示例流程不能勾选真实功能项。
