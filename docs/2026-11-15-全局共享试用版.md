## 实现范围

`QBoxGlobalNameSharing=true` 启用编译符号 `QBOX_GLOBAL_NAME_SHARING`。基础名称池允许复用任意距离的相同原始 UTF-16 文本，并保留全局字典，不采用标准版前 4,096 个全唯一名称后停止共享的分支。标准构建仍使用 256 KiB 回指窗口和原来的全唯一快速路径。

只共享文本，不合并节点、硬链接身份或名称记录；原匹配器、排序、稀疏预筛和前台生命周期保持原策略。USN 临时覆盖层仍顺序存储名称，基础合并时才应用共享。`ShareNameText(force: true)` 支持将已有局部共享 v2 再整理，保存时显式保活借用映射的索引所有者。

发布脚本将试用构建的 bin/obj 放在独立 SDK 产物目录，防止全局 DLL 混入后续标准构建。标准版归档的 SHA-256 仍为 `bcf2bbe8e908289055b3a0da7e267f0c15e72919c3db1e869868c37bb276ea72`。

## 复现

从仓库根发布独立试用 EXE：

```powershell
pwsh -File scripts/publish-desktop.ps1 -GlobalNameSharing -OutputDirectory work/global-trial-package
```

如需准备全局索引副本，先编译同一全局模式的探针，再以它执行转换：

```powershell
dotnet build tools/QBox.MemoryProbe -c Release -p:QBoxGlobalNameSharing=true -p:UseArtifactsOutput=true -p:ArtifactsPath=work/global-sharing-build
dotnet work/global-sharing-build/bin/QBox.MemoryProbe/release/QBox.MemoryProbe.dll --pack-live <source-index-directory> <new-trial-index-directory>
```

将尖括号参数换成实际目录。目标必须是新目录，不要指向正式缓存；需要重复对照时另选目标，工具不会覆盖已有试用数据。完整试用配置默认由全局 EXE 生成，本机已单独准备好。新环境的索引需自行建立，不依赖作者数据。
