# QBox 0.1.3 应用全拼增量

## 修改边界与 Git 基线

用户确认当前搜索效果大部分符合预期，要求大幅修改规则前先确认，并在下一次修改前用 Git 保存当前版本。

已先建立本地仓库，提交 `787e796`，标签 `v0.1.2`。基线包含源码、检查资料、`releases/0.1.2/QBox.exe` 与其哈希清单；没有纳入索引、临时研究文件、设置或用户历史。后续工作在 `feat/application-pinyin`。用户随后明确授权每个修改任务完成并验证后自动提交，本次增量据此提交并标记 `v0.1.3`。

本次是应用入口的独立全拼补充匹配。普通排序器 `LauncherOrdering.cs`、原字面匹配器 `FuzzyMatcher.cs`、文件索引预筛选及 `VolumeIndex.cs` 与基线没有改动。未来如需大幅调整这些规则，将先提供方案及前后对照，取得确认后再实施。

## 行为

- 已有字面匹配优先。应用入口名称未按原算法匹配时，才尝试连续汉字的完整拼音音节序列；支持多音字、大小写和含其他字符的应用名。
- 保留中文显示名称，拼音匹配位置映射回原 UTF-16 汉字范围，高亮保持准确。
- 拼音匹配作为最低应用分值的补充候选，低于已有有效字面应用匹配；使用原应用身份和原启动方式，选择后仍按既有历史学习。
- 本次范围为已载入的快捷方式及打包应用入口。没有扩大到全盘文件/目录、未注册的中文 EXE、首字母缩写或不完整音节匹配。读音表未收录的字继续支持原字面匹配，不保证拼音覆盖。

读音表采用 [mozillazg/pinyin-data](https://github.com/mozillazg/pinyin-data) 的固定提交 `fe29ad32bdf352b31a02b9936e537f575432e9a6`，版本 0.16.0，MIT 许可。44,440 个字符的读音转换为无声调形式，多音字通过有记忆的状态搜索匹配，未枚举读音的指数级组合。原始资料、许可和哈希保存在 `third_party/pinyin-data`，数据和许可均编译进核心库，运行时不联网。

## 验证

`scripts/verify.ps1`：685 组原始匹配分值对照、2,784 项行为/格式检查通过，Release 无警告、无错误。新增检查覆盖豆包、豆包工作、千问办公、多音字、大小写、UTF-16 补充平面高亮、字面匹配优先、完整音节边界、取消、动作别名归并、稳定身份、历史学习和完整命中计数。

|---|---|
| doubao | 第 1 豆包，第 2 豆包工作；对应“豆包”两字高亮 |
| qianwen | 第 1 千问办公；对应“千问”两字高亮 |

本轮没有实际启动用户应用，没有修改用户历史、索引或 Listary，也没有实施尚未确认的大幅规则变更。全局搜索其他待办继续保留，不将这次全拼增量视为与 Listary 完整等价。
