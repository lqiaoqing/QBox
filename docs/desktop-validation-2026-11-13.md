# 窗口版第一版验证

2026-11-14 续记：用户已明确确认双击 Ctrl 实测正常，本项不再待验。0.1.1 的排序、快捷方式合并及预筛选检查见 `search-validation-2026-11-14.md`；以下保留首版验证记录。

QBox.Desktop 使用本机 WPF 与 Windows Forms 托盘组件，产品不包含第三方 UI 运行库。发布入口为 `scripts/publish-desktop.ps1`，生成单个 `artifacts/QBox/QBox.exe`，使用已安装的 .NET 10 桌面运行时。

## 自动与真实数据检查

- Release 五项目构建无警告，685 组匹配对照、603 项行为检查通过。
- 新增查询版本检查：新输入取消旧请求，旧结果不能恢复；释放已完成请求后版本仍可核对；窗口退出取消运行中请求。
- 排序先完整判断命中并计数，仅对可能进入前列的候选计算对齐。排序前置字段以及分值上界的排除均不改变最终顺序；与完整排序的多卷、Unicode、历史和不同条数对照通过。
- 真实 C/D 索引在内存中合并查询 3,005,514 条文件/目录记录。更新后的五组查询总数与展示名称保持一致；旧查询取消及版本隔离通过。
- 独立窗口版更新工作进程读取预先写入的取消标记，退出码 130、状态 Cancelled、处理卷数为零，原索引哨兵文件逐字不变。没有管理员读取或覆盖真实索引。

仅用于判断优化方向的本机核心查询检查保存在 `work/desktop-engine-check/results*.log`。首次载入约 2 秒，预热后这些查询约 0.1～0.23 秒；这是核心查询的少量样本，不含完整 UI 与图标开销，也不代表已达到 Listary 的即时响应标准。没有收集 Listary 的性能数据。

## 真实窗口观察

窗口已载入 C/D 真实索引。800Q 显示 EG800Q 和 EG800Q 系列，nd 首位显示 Neat Download Manager，Tra 首位显示 Trae CN；名称与路径、匹配高亮、系统图标、命中总数和更多结果入口均在真实窗口中呈现。连续将输入替换为 Any、.code、800Q 后只保留最后的 800Q 结果。

初始受限测试环境未能注册全局快捷键。改在普通桌面环境启动后，窗口显示已注册 Ctrl+Alt+Space。再次启动同一状态目录的程序恢复了已有窗口，窗口 ID 不变且输入被选中。

测试 Ctrl+1 时触发现有截图工具浮层，后续键盘验证受其影响；默认结果快捷键因此改为 Alt+1～9，不修改用户其他工具的配置。完整键盘唤起、打开学习与管理员更新按钮交互仍需继续验收，不能将代码实现或注册成功当作全部交互已经验证。

用户随后要求改为双击 Ctrl，已实现原生键盘钩子及独立手势检测器，不记录或拦截用户按键。9 项新增检查覆盖左右 Ctrl、普通点击、组合键、长按、超时、重复按下、其他修饰键、左右重叠及系统计时器回绕。正式程序已重新发布并启动；后续界面验证因用户物理 Esc 操作使电脑操作工具停止，原生双击 Ctrl 的实际集成尚未完成自动验收。

## 当前边界

普通排序仍有目标排名不足及低相关结果靠前的问题，应用启动动作尚未统一去重，拼音未实现，索引更新目前由用户手动发起。重命名后的历史迁移与常驻 USN 监听仍未完成。窗口版第一版交付不等于用户要求的 Listary 级验收已经通过。
