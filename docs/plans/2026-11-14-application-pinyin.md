# 应用名称全拼匹配增量

用户已确认 0.1.2 大部分搜索结果符合预期。此后大幅修改匹配或排序前必须先获得确认。本次仅增加已授权的中文应用名全拼匹配，普通排序器、原有字面匹配器和文件索引预筛选规则保持原实现。

修改前已建立 Git 基线 `787e796`，标签 `v0.1.2`，包含源码、检查资料及已发布 EXE；开发在 `feat/application-pinyin`。原 EXE 哈希由 `releases/0.1.2/manifest.json` 保留。

应用名称先执行原有字面匹配；只有未匹配时才尝试全拼。全拼以连续汉字读音序列匹配，支持多音字，查询必须在音节边界结束；本次不增加首字母缩写、任意跳字或不完整音节匹配，控制新误匹配范围。

拼音结果使用应用入口及其原稳定身份，显示中文原名并高亮对应汉字。作为低于现有有效字面应用匹配的补充候选加入，复用历史学习。普通分组/排序键不改，不给 doubao、qianwen 等关键词编写特例。

读音表使用固定提交的开源 pinyin-data，保留许可、原始文件及生成脚本，编译时嵌入转换后的无声调读音表，不引入网络运行依赖或新的 NuGet 包。

验证包括豆包/豆包工作/千问办公（本机实际应用名）、多音字、中文高亮、大小写、别名动作去重、历史学习；同时对照 0.1.2 的 Any、800Q、.code、nd、Tra、chatgpt、rtt 的前九项和总数，确认既有查询没有回退。新增改动最初保持未提交供审阅；用户后续授权完成任务后自动提交，验证通过后据此标记 `v0.1.3`。
