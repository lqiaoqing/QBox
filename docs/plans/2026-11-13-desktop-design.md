# QBox 窗口版第一版

按用户“先交付可双击使用的窗口版”继续现有实施计划。采用已安装桌面框架中的 WPF，复用现有索引、搜索和历史核心，新增 QBox.Desktop，发布名称 QBox.exe。

界面采用紧凑浅色搜索栏：输入框、双行结果、匹配高亮、系统图标和键盘提示。上下键选择，回车打开，Esc 收起，Alt+1 至 Alt+9 打开对应项，更多按钮扩展显示。按用户后续要求，默认双击 Ctrl 唤起，允许用户切换快捷键；不修改 Listary。只接受短时间内两次单独按放 Ctrl，组合键、长按及左右 Ctrl 重叠不触发。真实测试中 Ctrl+1 触发现有截图工具，因此默认结果提示使用 Alt+数字，内部仍兼容 Ctrl+数字。

索引异步加载一次并驻留。每次输入取消前一请求，完成结果还需核对输入版本，旧结果不能覆盖或打开。索引重载失败保留旧快照并提示。打开前核对文件身份，仅成功提交 Shell 请求后记录历史。

普通界面使用普通权限。索引更新由用户点击后启动独立管理员工作进程，只写指定索引与状态文件；界面显示进度，完成后重新载入。第一版提供手动更新，常驻 USN 监听保持后续工作范围。

执行顺序：建立窗口与数据生命周期 → 键盘/托盘/打开 → 更新入口 → 发布单文件程序及真实界面验证。基础检查覆盖取消和版本隔离，界面用真实索引检查五类关键词、连续输入、收起唤起及选择行为。无 Git 暂存或提交。
